# cpp-learning-journey

A collection of C++ programs I wrote while learning programming. I add new files here as I learn new topics.

## Files

| File | What it does |
|------|--------------|
| `F1.cpp` | C++ fundamentals |
| `Matrix Multiplication.cpp` | Multiplies two 3x3 matrices using 2D arrays |

---

## F1.cpp – C++ Fundamentals

A program demonstrating core programming concepts.

**Topics covered:**
- Data types and literal suffixes (`float`, `long double`)
- Reference variables
- Type casting
- Operator precedence and associativity
- Basic arithmetic calculator using `switch`

---

## Matrix Multiplication.cpp – Arrays in C++

Creates two 3x3 matrices, multiplies them, and prints all three matrices.

**Topics covered:**
- 2D arrays
- Nested `for` loops
- Matrix multiplication

## How to Run

```bash
g++ "Matrix Multiplication.cpp" -o matrix
./matrix
```

On Windows, run `matrix.exe` instead of `./matrix`.
